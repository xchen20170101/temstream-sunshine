   - 先显示选择对话框，再执行操作

### 开机操作流程
```
用户点击"开机"按钮
    ↓

    └─ 提供"取消"按钮
    ↓
用户选择虚拟机
    ↓
弹出确认对话框
    ├─ 显示：虚拟机名称
    ├─ 显示：虚拟机状态
    ├─ 显示：虚拟机IP
    └─ 提供"取消"和"确定"按钮
    ↓
用户点击"确定"
    ↓
调用API执行开机操作
    ↓
显示操作结果
    ↓
自动刷新设备列表
```
