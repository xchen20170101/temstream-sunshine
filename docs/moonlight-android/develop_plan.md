# Moonlight Android 项目改造实施计划

## 项目概述

基于现有Moonlight Android应用进行改造，将自动网络发现机制替换为RESTful API云服务，并添加虚拟机管理功能。

## 当前项目分析

### 现有功能
- 自动mDNS网络发现功能
- PC配对机制（PIN码配对）
- 游戏流媒体功能
- PC管理界面

### 核心改造需求
1. **登录功能**：创建用户认证系统
2. **移除自动发现**：替换为RESTful API获取设备列表
3. **虚拟机控制**：添加开机/关机/重启等操作
4. **界面优化**：简化用户界面，移除不需要的功能

## RESTful API 接口规范

### 1. 用户登录
```
POST /api/cloud/v1/login
Request: {
  "username": "string",
  "password": "string"
}
Response: {
  "success": true,
  "token": "string",
  "expiry": "timestamp"
}
```

### 2. 获取设备列表
```
GET /api/cloud/v1/devices
Headers: Authorization: Bearer {token}
Response: {
  "success": true,
  "devices": [
    {
      "id": "string",
      "name": "string",
      "status": "online|offline",
      "ip": "string",
      "type": "string"
    }
  ]
}
```

### 3. 虚拟机操作
```
POST /api/cloud/v1/devices/{id}/action
Headers: Authorization: Bearer {token}
Request: {
  "action": "start|stop|restart"
}
Response: {
  "success": true,
  "message": "string"
}
```

## 风险评估

### 高风险项
1. 移除现有发现机制可能影响核心功能
2. API集成可能遇到网络兼容性问题

### 中风险项
1. UI界面改动可能影响用户体验
2. 新功能测试覆盖可能不够充分

### 风险缓解措施
1. 分阶段实施，每阶段充分测试
2. 保留原有代码注释，便于回滚
3. 充分测试网络异常情况
4. 保持现有游戏流媒体功能不变
