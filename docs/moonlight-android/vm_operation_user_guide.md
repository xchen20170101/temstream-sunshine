# 虚拟机操作功能使用指南

## 📱 功能说明

现在可以在执行虚拟机操作（开机、关机、重启）之前选择要操作的虚拟机了！

---

## 🎯 使用步骤

### 1️⃣ 开机操作

1. 点击控制面板中的 **"开机"** 按钮
2. 弹出虚拟机选择对话框
3. 从列表中选择要开机的虚拟机（显示格式：名称 (状态)）
4. 确认虚拟机信息（名称、状态、IP）
5. 点击"确定"执行开机操作

### 2️⃣ 关机操作

1. 点击控制面板中的 **"关机"** 按钮
2. 弹出虚拟机选择对话框
3. 从列表中选择要关机的虚拟机
4. 确认虚拟机信息
5. 点击"确定"执行关机操作

### 3️⃣ 重启操作

1. 点击控制面板中的 **"重启"** 按钮
2. 弹出虚拟机选择对话框
3. 从列表中选择要重启的虚拟机
4. 确认虚拟机信息
5. 点击"确定"执行重启操作

---

## 💡 虚拟机状态说明

在选择对话框中，每个虚拟机会显示当前状态：

- **运行中** - 虚拟机正在运行
- **已停止** - 虚拟机已停止
- **启动中** - 虚拟机正在启动
- **停止中** - 虚拟机正在停止
- **重启中** - 虚拟机正在重启

---

## 🔧 功能特性

✅ **智能提示** - 如果没有可用的虚拟机，会显示提示信息  
✅ **详细信息** - 确认时显示虚拟机的名称、状态和IP地址  
✅ **可取消** - 在选择对话框和确认对话框都可以取消操作  
✅ **自动刷新** - 操作成功后自动刷新设备列表，显示最新状态  
✅ **错误处理** - 操作失败时显示友好的错误提示

## ⚠️ 注意事项

1. **设备列表加载** - 确保在操作前设备列表已成功加载
2. **网络连接** - 需要网络连接才能执行虚拟机操作
3. **操作权限** - 需要有相应的虚拟机操作权限
4. **状态限制** - 某些操作可能受虚拟机当前状态限制

## 🆘 常见问题

### Q1: 点击开机按钮后显示"没有可用的虚拟机"？
**A**: 这可能是因为：
- 设备列表尚未加载完成，请稍等片刻后重试
- 当前账户没有任何虚拟机设备
- 网络连接问题导致设备列表获取失败

**解决方法**：点击刷新按钮重新加载设备列表

### Q2: 操作失败怎么办？
**A**: 可能的原因：
- **网络错误** - 检查网络连接
- **服务器错误** - 稍后重试
- **权限不足** - 确认账户有相应权限
- **虚拟机状态** - 确认虚拟机状态是否允许该操作

**解决方法**：根据错误提示进行相应处理

### Q3: 可以批量操作多个虚拟机吗？
**A**: 当前版本不支持批量操作，每次只能操作一个虚拟机。批量操作功能已列入后续优化计划。
